# MDiabolo 快速上手手册

这份手册给比赛现场使用。目标是在最短时间内完成开赛前设置、裁判评分、排名检查、导出成绩表和设备同步。

## 1. 开赛前准备

1. 安装并打开 `MDiabolo-release-latest.apk`。
2. 第一次使用时允许相机权限，之后才能扫描 QR 同步。
3. 确认首页显示正确的赛事名称。
4. 顶部按钮用途：
   - 管理员页面第一个按钮是登出。
   - 裁判页面没有返回按钮，只显示导出 QR、导入 QR、语言、字体/显示设置。
   - `中/EN` 可切换中文、英文、双语显示。
   - `A` 可调整字体大小和显示模式。

## 2. 管理员登录

1. 首页点击 `管理员`。
2. 第一次使用先注册管理员账号。
3. 之后输入管理员名字和密码登录。
4. 登录后进入 `比赛控制台`。

管理员控制台底部有 4 个主要页面：

- `排名 Ranking`
- `人员 People`
- `同步 Sync`
- `设置 Settings`

## 3. 建立赛事和比赛项目

1. 进入 `设置 Settings`。
2. 在 `赛事主题 Event theme` 新增或编辑赛事。
3. 新增赛事时填写：
   - 赛事华文名字
   - 赛事英文名字
4. 英文名字只能输入英文。如果输入华文，系统会提示错误。
5. 在 `比赛项目 Competition` 新增比赛项目。
6. 新增比赛时填写：
   - 比赛华文名字
   - 比赛英文名字
7. 点开比赛项目 accordion，设置：
   - 比赛状态：`Draft`、`Active`、`Completed`
   - 比赛类型：`个人舞台赛`、`双人/团体舞台赛`、`挑战赛`
8. 比赛必须设为 `Active / 进行中`，裁判端才会看到并评分。

## 4. 添加运动员

1. 进入 `人员 People`。
2. 在运动员区域填写：
   - 出场顺序
   - 个人名字/团队名字
   - 所属单位/团队
   - 国家/地区
   - 性别
   - 组别：小学组、中学组、公开组
3. 点击 `添加 Add`。
4. 如需修改运动员，点击运动员右侧铅笔图标。
5. 编辑区展开后可修改运动员资料。
6. 复制和移除按钮只显示 icon：
   - 复制 icon：复制运动员资料
   - 删除 icon：从当前比赛移除运动员

## 5. 添加裁判

1. 仍在 `人员 People`。
2. 在裁判区域填写：
   - 个人名字
   - 裁判类型：评分裁判或技术裁判
3. 点击 `添加 Add`。
4. 评分裁判负责输入分数。
5. 技术裁判负责记录失误次数。

裁判显示时只显示个人名字，不显示团队名字。

## 6. 裁判评分

1. 首页点击 `我是裁判`。
2. 选择裁判名字。
3. 选择当前可评分的比赛和运动员。
4. 评分裁判输入每个项目的分数。
5. 分数最高不能超过该项目上限。常见项目最高 30 分；输入超过 30 会自动变成 30。
6. 点击保存。
7. 保存后系统会回到运动员选择列表，继续选择下一位运动员。

技术裁判流程：

1. 选择运动员。
2. 使用 `+` / `-` 调整失误次数。
3. 点击保存。
4. 系统会按照设置里的每次失误扣分规则计算扣分。

裁判端返回逻辑：

- 如果正在评分某个运动员，返回会回到运动员选择。
- 不会直接退出到首页。

## 7. 查看排名和详细分数

1. 管理员进入 `排名 Ranking`。
2. 排名卡片会显示：
   - 名次
   - 裁判完成数
   - 对赛积分
   - 胜/和/负
   - 失误扣分
3. 点击某个运动员排名卡片，可查看详细分数。
4. 详情弹窗会显示：
   - 最终名次
   - 平均分
   - 对赛积分
   - 胜/和/负
   - 失误次数
   - 扣分
   - 每位裁判对这个运动员的所有评分项目
   - 原始总分、扣分后有效分、该裁判排名

如果某位裁判还没有提交该运动员分数，系统会显示未提交提示。

## 8. 导出 Excel 和 PDF

1. 管理员进入 `排名 Ranking`。
2. 点击 `导出 Excel` 或 `导出 PDF`。
3. 手机端会生成文件并打开/下载。
4. 文件名会使用当前赛事和比赛名称，不会再使用旧的预赛名称。
5. 如果导出后看到名字、成绩或排序不对，请先检查：
   - 是否选中了正确赛事
   - 是否选中了正确比赛
   - 裁判是否已完成评分
   - 技术裁判是否已保存失误记录

## 9. QR 同步

用于多台手机之间同步赛事、运动员、裁判、成绩、失误、设置等资料。

导出资料：

1. 在任意页面点击顶部 `导出 QR`。
2. 另一台设备点击 `导入 QR`。
3. 如果 QR 有多页，保持相机对准，系统会自动播放。

导入资料：

1. 点击顶部 `导入 QR`。
2. 扫描对方设备的 QR。
3. 系统会先显示同步预览。
4. 有冲突时可选择：
   - 保留本机
   - 接受 QR
5. 确认后才会写入资料。

## 10. 背景设置

1. 管理员进入 `设置 Settings`。
2. 找到背景设置。
3. 背景支持：
   - 渐变
   - 图片
   - 视频
4. 可调整透明度。
5. 可预览后再应用。
6. 应用后会写入系统设置，其他设备同步后也会看到同样背景。

## 11. 最常用现场流程

1. 管理员登录。
2. 设置赛事和比赛项目。
3. 把比赛状态设为 `Active`。
4. 添加运动员。
5. 添加评分裁判和技术裁判。
6. 裁判进入裁判端评分。
7. 技术裁判记录失误。
8. 管理员查看排名。
9. 点击排名卡片检查详细分数。
10. 导出 Excel/PDF。
11. 用 QR 同步到其他设备备份。

# MDiabolo 完整用户手册

MDiabolo 是一个离线优先的扯铃比赛计分系统，主要面向手机和平板使用。系统支持管理员建赛事、添加运动员和裁判、裁判现场评分、技术失误记录、席次法排名、Excel/PDF 导出、QR 离线同步，以及全系统背景自定义。

本手册按照真实比赛现场流程编写。

## 1. 系统角色

MDiabolo 有两个主要角色：

| 角色 | 主要工作 |
| --- | --- |
| 管理员 | 建立赛事和比赛项目、添加人员、查看排名、导出成绩、同步资料、设置背景 |
| 裁判 | 选择自己名字后，对运动员评分或记录失误 |

裁判分为两种：

| 裁判类型 | 工作 |
| --- | --- |
| 评分裁判 | 输入各评分项目分数 |
| 技术裁判 | 记录运动员失误次数，并产生扣分 |

## 2. 系统资料保存方式

MDiabolo 是离线优先系统。

- 所有资料会先保存在本机。
- 没有网络也可以继续比赛。
- Android App 使用本地 SQLite 保存资料。
- 浏览器开发模式会使用本地开发资料库或浏览器本地储存。
- 多台设备之间可以通过 QR 同步交换资料。

重要提醒：

- 比赛前请至少准备一台管理员主机。
- 比赛中建议定期使用 QR 导出备份。
- 多台设备同步时，导入前请仔细查看冲突预览。

## 3. 首页和顶部按钮

打开系统后会进入首页。

首页显示：

- 系统 Logo 和名称
- 当前赛事
- 裁判入口
- 管理员入口

顶部按钮常见用途：

| 按钮 | 用途 |
| --- | --- |
| 登出/返回位置 | 管理员页面第一个按钮是登出；裁判页面不显示返回按钮 |
| 导出 QR | 导出本机数据库同步资料 |
| 导入 QR | 扫描或粘贴其他设备的同步资料 |
| 中/EN | 切换中文、英文、双语显示 |
| A | 调整字体大小和显示模式 |

### 3.1 语言显示

系统支持：

- 双语显示
- 只显示中文
- 只显示英文

在双语模式下，英文作为辅助文字会显示得较小、较浅。运动员和裁判名字不会强制显示双语，系统会根据显示模式选择一个名字显示，避免列表太拥挤。

### 3.2 字体和显示设置

点击 `A` 可调整显示设置。

常见用途：

- 手机屏幕较小时调小字体
- 投屏或平板使用时调大字体
- 需要更干净界面时使用简化显示

## 4. 管理员账号

### 4.1 第一次注册

1. 首页点击 `管理员`。
2. 如果系统还没有管理员账号，会进入注册模式。
3. 输入管理员名字和密码。
4. 点击注册。

### 4.2 登录

1. 首页点击 `管理员`。
2. 输入管理员名字和密码。
3. 登录后进入 `比赛控制台`。

### 4.3 登出

管理员页面顶部第一个按钮是 `登出`。管理员只有点击登出才会退出账号。返回按钮逻辑不会直接登出。

## 5. 管理员控制台

管理员控制台底部有 4 个主要页面：

| 页面 | 用途 |
| --- | --- |
| 排名 Ranking | 查看排名、查看运动员详细分数、导出 Excel/PDF |
| 人员 People | 添加、编辑、复制、移除运动员和裁判 |
| 同步 Sync | 查看同步资料、设置本机同步身份、查看 QR 整合记录 |
| 设置 Settings | 赛事、比赛项目、扣分规则、人员信息、背景、当前赛事等设置 |

## 6. 设置赛事

赛事是首页显示的比赛活动名称，例如 `Malaysia International Diabolo Competition 2026`。

### 6.1 新增赛事

1. 管理员进入 `设置 Settings`。
2. 找到 `赛事主题 Event theme`。
3. 填写：
   - 新赛事华文名字
   - 新赛事英文名字
4. 点击 `新增赛事`。

英文名字输入规则：

- 英文栏位不能输入华文。
- 如果粘贴或输入华文，系统会提示错误。
- 数字、空格和常见符号可以使用，例如 `Open 2026`。

### 6.2 设置首页当前赛事

1. 在 `设置 Settings` 找到 `首页当前赛事`。
2. 从下拉菜单选择要显示在首页的赛事。
3. 其他设备通过 QR 同步后，也会使用同一设置。

## 7. 设置比赛项目

比赛项目属于赛事下面的具体项目，例如个人舞台赛、双人舞台赛、挑战赛。

### 7.1 新增比赛项目

1. 管理员进入 `设置 Settings`。
2. 先确认顶部赛事下拉选择正确。
3. 找到 `比赛项目 Competition`。
4. 填写：
   - 新比赛华文名字
   - 新比赛英文名字
5. 点击 `新增比赛`。

### 7.2 编辑比赛项目

新增后的比赛项目会以 accordion 形式收起。

1. 点击某个比赛项目标题展开。
2. 可编辑：
   - 华文名字
   - 英文名字
   - 比赛状态
   - 比赛类型

比赛状态：

| 状态 | 说明 |
| --- | --- |
| Draft / 草稿 | 尚未开放，裁判端看不到 |
| Active / 进行中 | 当前可评分，裁判端可看到 |
| Completed / 已完成 | 已完成，通常用于归档 |

比赛类型：

| 类型 | 说明 |
| --- | --- |
| 个人舞台赛 | 个人舞台类评分项目 |
| 双人/团体舞台赛 | 双人或团体舞台类评分项目 |
| 挑战赛 | 挑战赛评分项目 |

比赛类型会影响裁判端出现哪些评分维度。

## 8. 运动员管理

进入 `人员 People` 页面左侧/上方的运动员区域。

### 8.1 新增运动员

可填写：

| 字段 | 说明 |
| --- | --- |
| 出场顺序 | 排序和现场出场使用 |
| 个人名字/团队名字 | 个人或队伍显示名称 |
| 所属单位/团队 | 学校、协会、队伍或单位 |
| 国家/地区 | 代表国家或地区 |
| 性别 | 男、女、混合 |
| 组别 | 小学组、中学组、公开组 |

点击 `添加` 后，运动员会加入当前选择的比赛项目。

注意：

- 同一个比赛内出场顺序不能重复。
- 如果输入重复顺序，系统会提示更换。
- 新增后会自动进入当前比赛的第一份参赛名单。

### 8.2 编辑运动员

1. 在运动员列表找到目标运动员。
2. 点击铅笔 icon。
3. 编辑区会展开。
4. 可修改：
   - 出场顺序
   - 个人名字/团队名字
   - 所属单位/团队
   - 国家/地区
   - 性别
   - 组别
5. 修改后会自动保存，并显示保存反馈。

### 8.3 复制运动员资料

点击复制 icon，可复制运动员资料，方便发给工作人员或核对名单。

### 8.4 移除运动员

点击删除 icon，会把运动员从当前比赛移除。

说明：

- 这是从当前比赛移除，不一定代表全系统彻底删除该运动员。
- 如果运动员已在其他比赛中使用，其他比赛不受影响。

### 8.5 从其他比赛快速加入运动员

如果系统里已有其他比赛的运动员，`快捷加入其他比赛选手` 区域会显示可加入的人。

1. 勾选一个或多个运动员。
2. 点击加入。
3. 系统会自动避免当前比赛出场顺序冲突。

## 9. 裁判管理

进入 `人员 People` 页面裁判区域。

### 9.1 新增裁判

填写：

| 字段 | 说明 |
| --- | --- |
| 个人名字 | 裁判显示名称 |
| 裁判类型 | 评分裁判或技术裁判 |

点击 `添加` 后，裁判会加入当前比赛。

说明：

- 裁判只需要个人名字，不需要团队名字。
- 裁判端显示裁判名字时只显示个人名字。

### 9.2 从其他比赛加入裁判

如果系统里已有其他比赛的裁判，可从 `从其他比赛加入现有裁判` 下拉菜单选择，再点击加入本比赛。

### 9.3 移除裁判

点击裁判右侧删除 icon，会把该裁判从当前比赛移除。

## 10. 设置扣分规则和导出人员信息

在 `设置 Settings` 可设置当前比赛的技术失误扣分规则和导出表上的人员信息。

### 10.1 技术失误规则

字段：

- 每次失误扣分

常见值：

- `0.3`
- `0.5`

技术裁判保存失误次数后，系统会用这个值计算总扣分。

### 10.2 比赛人员信息

可填写：

- 裁判长
- 记录员

这些资料会出现在导出的 Excel/PDF 成绩表中。

## 11. 裁判端操作

### 11.1 进入裁判端

1. 首页点击 `我是裁判`。
2. 选择自己的名字。
3. 系统会显示该裁判被分配到的 `Active / 进行中` 比赛。

如果裁判看不到比赛，请检查：

- 管理员是否把比赛状态设为 `Active`
- 裁判是否已经加入当前比赛
- 运动员是否已加入当前比赛名单

### 11.2 选择运动员

裁判端会显示运动员列表。

可使用：

- 搜索
- 按出场顺序排序
- 按姓名排序
- 按国家排序
- 按学校排序
- 按完成状态排序

点击运动员进入评分。

返回逻辑：

- 如果正在评分某个运动员，返回会回到运动员选择列表。
- 不会直接退出裁判端。

### 11.3 评分裁判输入分数

评分裁判会看到比赛类型对应的评分项目。

操作：

1. 输入每个评分项目分数。
2. 分数不能小于 0。
3. 分数不能超过该项目上限。
4. 常见评分项目上限是 30 分，服装类可能是 10 分。
5. 如果输入超过上限，系统会自动限制到上限。
6. 点击保存。

保存后：

- 系统会显示已保存。
- 本机先保存资料。
- 运动员会标记为已完成。
- 裁判回到运动员选择列表，可继续评分下一位。

### 11.4 技术裁判记录失误

技术裁判不会输入评分维度，而是记录失误次数。

操作：

1. 选择运动员。
2. 用 `+` 增加失误次数。
3. 用 `-` 减少失误次数。
4. 点击保存。

系统会自动计算：

```text
总扣分 = 失误次数 × 每次失误扣分
```

## 12. 排名系统

管理员进入 `排名 Ranking` 查看成绩。

### 12.1 排名卡片

每位运动员排名卡片显示：

- 名次
- 完成评分的裁判数
- 对赛积分
- 胜/和/负
- 失误扣分

可使用搜索和排序：

- 按名次
- 按对赛积分
- 按平均分
- 按完成裁判数
- 按出场顺序
- 按姓名

### 12.2 席次法和对赛积分

系统使用席次法的思路计算排名。

大致逻辑：

1. 每位裁判对当前运动员给出总分。
2. 系统按每位裁判的分数产生该裁判下的名次。
3. 运动员两两比较。
4. 多数裁判认为某运动员排名更高，则该运动员赢得这次对赛。
5. 赢得对赛得到对赛积分。
6. 最终按完成状态、对赛积分、平均分、出场顺序排序。

如果裁判未完成全部评分，系统会显示完成数，未完成资料会影响完整排名判断。

### 12.3 查看运动员详细分数

点击排名卡片可打开详细分数弹窗。

弹窗显示：

- 最终名次
- 平均分
- 对赛积分
- 胜/和/负
- 失误次数
- 扣分
- 每位裁判的评分详情

每位裁判明细包含：

- 该裁判名字
- 各评分项目分数
- 原始总分
- 扣分后有效分
- 该裁判下的运动员名次

如果某位裁判还没有提交，会显示未提交提示。

## 13. 导出 Excel 和 PDF

### 13.1 导出位置

管理员进入 `排名 Ranking`。

点击：

- `导出 Excel`
- `导出 PDF`

### 13.2 导出内容

导出表包含：

- 赛事名称
- 比赛项目名称
- 裁判长
- 记录员
- 运动员排名
- 每位裁判分数
- 技术失误扣分
- 最终排名资料

### 13.3 手机端打开文件

Android App 会生成文件并尝试打开或分享下载。

如果无法打开：

1. 确认手机是否安装可打开 Excel/PDF 的 App。
2. 使用系统分享保存到 Downloads。
3. 重新导出一次。

### 13.4 文件名说明

导出文件名会使用当前赛事和当前比赛项目名称。

如果文件名看起来不对，请检查管理员顶部选择的赛事和比赛项目是否正确。

## 14. QR 同步

QR 同步用于多台设备之间离线交换资料。

会同步的资料包括：

- 赛事
- 比赛项目
- 运动员
- 裁判
- 成绩
- 技术失误
- 管理员资料
- 系统设置

### 14.1 导出 QR

1. 点击顶部 `导出 QR`。
2. 系统显示一个或多个 QR。
3. 如果资料较多，QR 会自动分页播放。
4. 另一台设备保持相机对准即可扫描。

也可点击复制导入数据，用文字方式传给另一台设备粘贴导入。

### 14.2 导入 QR

1. 点击顶部 `导入 QR`。
2. 使用相机扫描另一台设备 QR。
3. 如果设备不支持相机扫描，可粘贴 QR 数据导入。
4. 系统会显示同步预览。
5. 确认后才会写入本机。

### 14.3 冲突处理

如果本机和 QR 都有同一笔资料但内容不同，系统会显示冲突。

你可以选择：

| 选项 | 说明 |
| --- | --- |
| 保留本机 | 不采用 QR 的修改 |
| 接受 QR | 使用 QR 里的版本 |

建议：

- 成绩和失误记录通常选择时间较新的版本。
- 系统设置会影响全场，确认后再接受 QR。
- 不确定时先保留本机，再询问裁判长或记录员。

### 14.4 同步记录

管理员进入 `同步 Sync` 可查看 QR 整合记录，包括：

- 导出者
- 来源时间
- 新增数量
- 接受修改数量
- 删除数量
- 保留本机数量

## 15. 背景设置

管理员进入 `设置 Settings` 可自定义系统背景。

支持类型：

| 类型 | 说明 |
| --- | --- |
| 渐变 | 输入 CSS 渐变或选择预设 |
| 图片 | 使用图片地址或上传/保存后的图片资源 |
| 视频 | 使用视频作为系统背景 |

可调整：

- 背景类型
- 背景值
- 透明度
- 预览
- 应用
- 恢复默认背景
- 使用历史背景

视频背景建议：

- 使用较短、较小的循环视频。
- 避免过亮画面影响文字可读性。
- 现场设备性能较弱时，优先使用图片或渐变。

## 16. 返回和登出逻辑

系统返回逻辑会根据当前页面状态处理。

管理员：

- 顶部第一个按钮是登出。
- 页面内不会散落多个登出按钮。
- 返回不会直接登出。
- 管理员要退出必须点击登出。

裁判：

- 裁判页面顶部没有返回按钮。
- 如果正在评分运动员，返回会回到运动员选择。
- 再返回才离开裁判流程。

弹窗：

- 有弹窗时返回会优先关闭弹窗。
- 例如 QR、排名详情、背景预览等。

## 17. 常见问题

### 17.1 裁判看不到比赛

检查：

1. 比赛状态是否是 `Active / 进行中`。
2. 裁判是否已加入当前比赛。
3. 当前选择的赛事和比赛是否正确。
4. 是否已有运动员加入当前比赛。

### 17.2 排名没有出来

检查：

1. 是否已有运动员。
2. 评分裁判是否提交分数。
3. 技术裁判是否保存失误记录。
4. 管理员是否选中了正确比赛。
5. 是否还有裁判未完成评分。

### 17.3 详细分数里显示裁判未提交

表示系统没有找到该裁判对该运动员的评分记录。

处理：

1. 让该裁判进入裁判端。
2. 选择相同比赛和运动员。
3. 输入分数并保存。
4. 管理员刷新或重新打开排名详情。

### 17.4 Excel 或 PDF 打不开

处理：

1. 确认手机有 Excel/PDF 阅读器。
2. 尝试分享到 Downloads。
3. 重新导出。
4. 如果仍失败，用另一台设备导入 QR 后导出。

### 17.5 英文输入不能输入华文

这是正常规则。

以下字段要求英文：

- 赛事英文名字
- 比赛英文名字

如果需要华文，请填写在华文名字栏位。

### 17.6 分数输入超过 30 会变成 30

这是正常保护。

评分项目有最高分限制。输入超过上限时，系统会自动改成最高分，避免裁判误输入。

### 17.7 多台设备资料不同

使用 QR 同步。

建议流程：

1. 分数设备导出 QR。
2. 管理员主机导入 QR。
3. 检查冲突。
4. 确认整合。
5. 管理员主机再导出 QR 给其他设备。
